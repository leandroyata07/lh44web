# LH44 - WebGL Edition 🏎️💨

> Jogo de corrida retrô 2.5D estilo arcade (Top Gear / OutRun) acelerado por hardware via WebGL.

## 🌟 Destaques
- **Renderização via GPU (WebGL Nativo):** Asfalto, zebras, acostamentos e pistas renderizados em lote (*batching*) diretamente pelos Vertex & Fragment Shaders da GPU.
- **Alta Taxa de Quadros:** Otimizado para rodar a 60-120 FPS sem gargalos de CPU/Canvas 2D.
- **27 Circuitos Brasileiros:** Todos os estados do Brasil com perfis de elevação, curvas, monumentos locais e clima dinâmico (Dia, Tarde, Noite, Chuva, Neve).
- **20 Pilotos e Grid Completo:** Inteligência artificial com vácuo (*slipstream*), colisão balanceada e nitro.
- **Suporte Total a Controles:** Compatível com Teclado, Joysticks/Gamepads nativos (Xbox, PlayStation, GameSir) e Controles Virtuais Touch para dispositivos móveis.
- **Zero Dependências:** Código puro, rápido e leve, pronto para rodar em qualquer navegador moderno.

## 🚀 Como Jogar
Basta abrir o arquivo `index.html` em qualquer navegador web moderno.
